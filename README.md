## Como eu desenvolvo

<div align="center">

**Problema → Análise → Implementação → Testes → Refatoração → Evolução**

</div>

Antes de escolher uma tecnologia, procuro entender o problema. Escrevo o teste antes do código quando possível, mantenho as mudanças pequenas e revisáveis e cuido do que vem depois da entrega: tratamento de erros, segurança e manutenção.
